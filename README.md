# Proyecto Katas de Python

## Descripción del Proyecto
Este repositorio contiene la resolución documentada de **41 Katas de Python** (ejercicios prácticos de programación). El objetivo principal de este proyecto es mejorar y afianzar las habilidades lógicas y de codificación mediante la repetición y la resolución de desafios propuestos. Los ejercicios abarcan desde el tratamiento básico de textos y matemáticas, hasta la manipulación de datos complejos y la Programación Orientada a Objetos.

---

## Tecnologías y Herramientas
* **Lenguaje:** Python 3
* **Entorno de Desarrollo (IDE):** Visual Studio Code
* **Control de Versiones:** Git & GitHub

---

## Resumen de Habilidades Demostradas
A lo largo del código, se demuestra el dominio práctico de los siguientes conceptos exigidos por el proyecto

1. **Tipos de Datos y Funciones Incorporadas:** Uso de strings, enteros, flotantes y manejo fluido de funciones nativas de Python (`map`, `filter`, `reduce`, `len`, `sorted`)
2. **Estructuras de Datos:** Manipulación y transformación de listas, diccionarios, tuplas y sets (conjuntos), incluyendo técnicas como el *slicing*
3. **Control de Flujo:** Uso de condicionales lógicos (`if`, `elif`, `else`) para la toma de decisiones
4. **Estructuras de Iteración:** Recorrido eficiente de colecciones mediante bucles `for` y comprensión de listas
5. **Manejo de Funciones:** Creación de funciones tradicionales (`def`), funciones anónimas (`lambda`) y funciones con cantidad variable de argumentos (`*args`)
6. **Programación Orientada a Objetos (POO):** Creación de Clases, métodos, inicializadores (`__init__`) y el uso de `self` para representar entidades (ej. clase `Arbol` y `UsuarioBanco`)
7. **Prevención de Errores y Módulos:** Implementación de bloques `try/except`, lanzamiento de excepciones personalizadas (`raise ValueError`) y uso de módulos
8. **Buenas Prácticas:** Código limpio y ordenado

---

## Cómo explorar este proyecto
1. El archivo principal con la solución es un archivo `.py` llamado `katas.py` que incluye la resolución secuencial de todos los ejercicios
2. Cada Kata está encabezada con un comentario que detalla el enunciado original para dar contexto a la solución programada
3. Además de la lógica principal, se han incluido bloques de prueba ("Casos de uso") para ejecutar y validar el funcionamiento individual de cada función o clase.
4. Se han añadido comentarios explicativos en los bloques de código más complejos, documentando el razonamiento detrás de cada solución
